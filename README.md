Скрипт `install_xray.sh` — решение «всё в одном» (All-in-One) для автоматизированного развертывания и администрирования многопротокольного защищенного сетевого шлюза (**VLESS TCP XTLS-Vision**, **VLESS gRPC** и **Hysteria 2**) на Linux VPS/VDS.

Проект разработан для организации надежных зашифрованных каналов связи, снижения сетевых задержек (Jitter/Latency) в мобильных и корпоративных сетях, а также централизованного управления конфигурациями устройств. Архитектура скрипта изолирована и безопасна для параллельной работы с другими сетевыми комплексами (например, **AntiZapret**).

## 🛠️ Технологический стек (Tech Stack)

- **Языки и автоматизация**: Bash 5.x, Python 3 (демон динамических конфигураций и генератор подписок)
- **Транспортные ядра**: Xray-core (VLESS + XTLS-Vision на порту 443, VLESS + XHTTP на порту 8443, VLESS + gRPC multiMode на порту 2053), Hysteria 2 (UDP QUIC на порту 443 / 20443 с Port Hopping `20000:50000`)
- **Поддерживаемые ОС**: Debian 11 / 12 / 13, Ubuntu 20.04 / 22.04 / 24.04 (x86_64)
- **Ядро и Сеть**: Xanmod Kernel (x64v1-v3), TCP BBR, ZRAM (LZ4) + Disk Swap, PMTU MSS Clamping, Systemd/Journald Tuning
- **Двухканальный обход (Dual-Egress)**: Cloudflare WARP (WireGuard) для AI и стриминга + Psiphon (Docker SOCKS5) для Google & Gemini
- **Резервный сервис (Fallback)**: Локальный веб-сервис с порталом документации (RU/EN)

## 📋 Требования к серверу (Prerequisites)

1. **Операционная система**: Чистая Debian 11/12/13 или Ubuntu 20.04/22.04/24.04 с правами `root`.
2. **Домен и DNS**: Зарегистрированный домен с настроенной **A-записью**, указывающей на публичный IPv4-адрес вашего сервера (например, `sub.domain.com -> 1.2.3.4`).
3. **Сетевые порты**:
   - `80/tcp` — получение валидных TLS-сертификатов Let's Encrypt / Certbot.
   - `443/tcp` — защищенный шлюз VLESS TCP XTLS-Vision.
   - `443/udp` & `20443/udp` — высокоскоростной шлюз Hysteria 2 (QUIC).
   - `8443/tcp` — шлюз VLESS XHTTP (HTTP/2 + динамический padding 100-1000 байт).
   - `2053/tcp` — резервный шлюз VLESS gRPC (HTTP/2, `multiMode: true`).
   - `20000:50000/udp` — диапазон динамических портов (Port Hopping) для Hysteria 2.

## ✨ Ключевые возможности

* 🚀 **Протокол VLESS TCP XTLS-Vision (Порт 443 TCP)**: Прямое TLS 1.3 соединение со стандартным профилем клиентского рукопожатия (`fp=chrome` по умолчанию, настраивается на `safari`, `ios`, `firefox`, `random`). Неотличим от легитимного HTTPS веб-трафика.
* ⚡ **Hysteria 2 (Порт 20443 UDP / Port Hopping 20000-50000)**: Протокол на базе UDP/QUIC (BBR/Brutal) для стабильной связи и минимального RTT в мобильных сетях. Использование высокого порта `20443` и диапазона Port Hopping защищает от блокировок UDP 443 со стороны ТСПУ.
* 🛡️ **Протокол VLESS XHTTP (Порт 8443 TCP)**: Современный транспорт поверх HTTP/2 с рандомизированным паддингом пакетов (`xPaddingBytes: 100-1000`) для маскировки паттернов трафика и совместимости с CDN (Cloudflare).
* ↔️ **Протокол VLESS gRPC (Порт 2053 TCP)**: Резервный мультиплексированный канал поверх HTTP/2 и TLS с поддержкой `multiMode: true` для параллельных сессий.
* 📱 **Сервер динамических конфигураций (Base64 / JSON)**: Локальный сервис генерирует персональные профили подключения (`https://ваш-домен.com/sub/UUID`). Совместим с приложениями **Happ**, **Incy**, **Hiddify**, **v2rayN**, **Shadowrocket**, **Clash/Mihomo**, **SingBox**. Поддерживает `server-address-resolve-enable: 1` для предотвращения DNS deadlock в TUN-режиме.
* 🧭 **Динамические профили маршрутизации клиентов (Routing Profiles)**:
  * **Default**: Обход блокировок для пользователей из РФ (рунет напрямую, заблокированные ресурсы через сервер).
  * **Relocant**: Для релокантов за рубежом (весь мировой трафик напрямую, а сервисы РФ — через сервер).
  * **Whitelist**: Строгий режим белых списков РФ.
  * **Off**: 100% трафика направляется через туннель без разделения.
* 🌐 **Разблокировка Google & Gemini через Psiphon**:
  * Изолированный Docker-клиент Psiphon с локальным SOCKS5-прокси.
  * Автоопределение локации VPS: если сервер находится в стране без поддержки Gemini (например, Турция `TR`, РФ `RU`), скрипт автоматически переключает выход на Германию (`DE`).
  * Полный охват сессии Google (`gemini.google.com`, `aistudio.google.com`, `googleapis.com`, `gstatic.com`, `googleusercontent.com`, `google.com`) для предотвращения расщепления сессий `IP: A ≠ B`.
  * Блокировка UDP для принудительного переключения браузеров с QUIC на TCP.
  * Трафик YouTube (`youtube.com`, `googlevideo.com`) направляется напрямую (`DIRECT`), предотвращая просадку скорости видео.
* 🌀 **Селективная маршрутизация через Cloudflare WARP**:
  * **Smart (Рекомендуемый)**: Направляет через Cloudflare только AI-сервисы (ChatGPT, Claude, Perplexity, Grok, ElevenLabs), Spotify (включая стриминговые CDN Akamai/pscdn), TikTok и соцсети.
  * **Full**: Направляет весь исходящий трафик сервера через Cloudflare.
  * Защита от утечек IPv6 (`domainStrategy: UseIPv4`), сброса NAT (`PersistentKeepalive = 25`) и автообновление геоблоков через cron.
* 🧅 **Встроенный шлюз Tor (.onion SOCKS5)**: Прозрачное проксирование `.onion`-доменов через локальный Tor-демон (`127.0.0.1:9050`) без необходимости открывать Tor Browser.
* 💾 **Резервное копирование и восстановление (Backup & Restore)**: Создание полных снепшотов конфигураций (Xray, Hysteria 2, SSL-сертификаты, Psiphon, Tor, службы systemd) с ротацией 7 последних копий и быстрыми командами `--backup` / `--restore`.
* 🛡️ **Многоуровневая фильтрация угроз**: Блокировка рекламы, опасных портов (25, 445 и др.), торрентов и вредоносных ресурсов на уровне ядра Xray.
* 🎭 **Адаптивный камуфляж (Decoy / Selfsteal)**: Возможность развертывания реалистичного enterprise веб-сайта на Nginx-заглушке подлинного домена для активных DPI-сканеров.
* ⚡ **Комплексная оптимизация VPS**:
  * **Гибридная память**: ZRAM (50-60% RAM с LZ4) + 2GB Disk Swap (с защитой свободного диска $\ge$ 4GB).
  * **Сетевой стек**: Тюнинг `sysctl` (`fs.file-max=67M`, BBR, TCP Fast Open, динамические буферы по `_PHYS_PAGES` до 32MB).
  * **Мобильный KeepAlive**: `tcp_keepalive_time = 60s` для предотвращения сбросов сессий в мобильных сетях.
  * **Многопоточность (RPS)**: Автоматическое распределение очередей сетевых карт по всем ядрам CPU.
  * **PMTU Fix**: Автоматический TCP MSS Clamping против фрагментации пакетов.
  * **Персистентный Port Hopping**: Автоматическое внедрение NAT-таблицы в `/etc/ufw/before.rules` (`20000:50000/udp -> 443`).
  * **Ядро Xanmod**: Автоматическая сборка под процессорную архитектуру (v1-v3).

## 🏷️ Формат профилей и обозначений

При импорте конфигурации в клиентское приложение формируются следующие профили подключения:

| Протокол | Формат имени в клиенте | Порт и транспорт | Назначение |
|---|---|---|---|
| **VLESS TCP** | `🇳🇱🌐 VLESS-TCP` | `443/tcp` (XTLS-Vision, TLS 1.3) | Основной высокоскоростной профиль для дома, оптоволокна и ПК |
| **VLESS XHTTP** | `🇳🇱🛡️ VLESS-XHTTP` | `8443/tcp` (XHTTP, HTTP/2 + padding) | Обход DPI с рандомизацией размера пакетов и совместимость с CDN |

| **Hysteria 2** | `🇳🇱⚡ Hysteria2` | `20443/udp` (QUIC, hopping `20000:50000`) | Низкие задержки и высокий CPS в мобильных и нестабильных сетях |
| **VLESS Reality** | `🇳🇱🪞 VLESS-Reality` | `443/tcp` (Reality) | Режим маскировки под внешние веб-ресурсы (опционально) |

## ⚙️ Дополнительные режимы запуска

```bash

```

### Восстановление из резервной копии

```bash
# Восстановление из последней созданной копии
sudo bash install_xray.sh --restore latest

# Восстановление из конкретного архива
sudo bash install_xray.sh --restore /var/backups/xray/xray_backup_20260915_120000.tar.gz
```

```bash
sudo bash install_xray.sh --renew-cert
```

### Headless-режим (Автоматическая установка без диалоговых окон)

```bash
sudo bash install_xray.sh --headless <домен> <email> <кол-во_устройств> [имена_устройств...]
```

```bash
sudo bash install_xray.sh --headless vpn.mysite.com admin@mail.com 3 "iPhone" "Macbook" "HomePC"
```

```bash
sudo bash install_xray.sh --update-geoblocks
```

## 🤝 Совместимость с локальными шлюзами (AntiZapret)

Проект спроектирован для безопасного и изолированного сосуществования с **AntiZapret** на одном хосте:

1. Инсталлятор автоматически определяет наличие правил и служб AntiZapret (`openvpn-server@antizapret-*`, `knot-resolver`, таблицы iptables).
2. UFW отключается во избежание конфликта цепочек.
3. Необходимые порты Xray и Hysteria (`80, 443, 2053, 8443 TCP` и `443, 20000:50000 UDP`) вставляются на **1-ю и 2-ю позиции цепочки `INPUT`**, что предотвращает их попадание в ловушку `antizapret-block`.
4. Внутренние службы AntiZapret, списки блокировок и маршрутизация DNS остаются полностью работоспособными и автономными.

## ❓ Troubleshooting & Часто задаваемые вопросы (FAQ)

### 1. Почему Google и Gemini требуют Psiphon, а не WARP?
* Google классифицирует диапазоны Cloudflare WARP как принадлежащие РФ независимо от физической локации эндпоинта WARP. Попытка направить Gemini через WARP приводит к ошибке *«Не поддерживается в вашей стране»*.
* Psiphon имеет чистые европейские пулы IP с высокой репутацией для Google. При этом скрипт блокирует UDP для доменов Google, принуждая браузеры мгновенно откатываться с QUIC на TCP.

### 2. Что делать, если Google выдает капчу при активном Psiphon?
* Выполните ротацию выходного IP в консоли сервера:
  ```bash
  vps-psiphon rotate
  ```
  Или через меню `xry` -> пункт `4` (Обходы) -> пункт `15` («Ротация IP Psiphon»).

### 3. Как переключить сервер на маршрутизацию для релокантов?
* Если ваш сервер находится на территории РФ или вы живете за границей и хотите посещать заблокированные извне российские сервисы (Госуслуги, банки, Кинопоиск):
  * Запустите `xry` -> пункт `4` (Обходы) -> пункт `10` («Сменить профиль маршрутизации»).
  * Выберите профиль **`2` (Relocant)**. Весь мировой интернет пойдет напрямую с вашего устройства, а трафик РФ — через ваш сервер.

### 4. Ошибка при получении сертификата Certbot ("Порт 80 занят")
* **Причина**: На сервере уже активен другой веб-сервер (Nginx, Apache, Caddy).
* **Решение**: Временно остановите конфликтующую службу (`systemctl stop nginx`) на время получения сертификата.

### 5. Соединение Hysteria 2 не устанавливается на облачном VPS
* **Причина**: В панели управления облачной инфраструктуры (Security Groups / Firewall) не открыты входящие UDP-порты.
* **Решение**: Добавьте разрешающие входящие правила для `443/udp` и диапазона `20000:50000/udp`.

### 6. Как обновить скрипт и применить последние исправления?
* Запустите `xry`, выберите пункт **`9`** («Обновить скрипт с GitHub и применить новые фиксы»).
