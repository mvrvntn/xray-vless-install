Скрипт `install_xray.sh` — решение «всё в одном» (All-in-One) для автоматизированного развертывания и администрирования многопротокольного защищенного сетевого шлюза (**VLESS TCP XTLS-Vision**, **VLESS gRPC** и **Hysteria 2**) на Linux VPS/VDS.

Проект разработан для организации надежных зашифрованных каналов связи, снижения сетевых задержек (Jitter/Latency) в мобильных и корпоративных сетях, а также централизованного управления конфигурациями устройств. Архитектура скрипта изолирована и безопасна для параллельной работы с другими сетевыми комплексами (например, **AntiZapret**).

## 🛠️ Технологический стек (Tech Stack)

- **Языки и автоматизация**: Bash 5.x, Python 3 (демон динамических конфигураций)
- **Транспортные ядра**: Xray-core (VLESS + XTLS-Vision на порту 443, VLESS + gRPC на порту 8443), Hysteria 2 (UDP QUIC на порту 443)
- **Поддерживаемые ОС**: Debian 11 / 12 / 13, Ubuntu 20.04 / 22.04 / 24.04 (x86_64)
- **Ядро и Сеть**: Xanmod Kernel (x64v1-v3), TCP BBR, ZRAM (LZ4) + Disk Swap, PMTU MSS Clamping, Systemd/Journald Tuning
- **Маршрутизация и шлюзы**: Cloudflare WARP (WireGuard), Выделенный SOCKS5 Proxy для AI-сервисов, селективные списки маршрутизации
- **Резервный сервис (Fallback)**: Локальный веб-сервис с порталом документации (RU/EN)

## 📋 Требования к серверу (Prerequisites)

1. **Операционная система**: Чистая Debian 11/12/13 или Ubuntu 20.04/22.04/24.04 с правами `root`.
2. **Домен и DNS**: Зарегистрированный домен с настроенной **A-записью**, указывающей на публичный IPv4-адрес вашего сервера (например, `sub.domain.com -> 1.2.3.4`).
3. **Сетевые порты**:
   - `80/tcp` — получение валидных TLS-сертификатов Let's Encrypt / Certbot.
   - `443/tcp` — защищенный шлюз VLESS TCP XTLS-Vision.
   - `443/udp` — высокоскоростной шлюз Hysteria 2 (QUIC).
   - `8443/tcp` — резервный шлюз VLESS gRPC (HTTP/2).
   - `20000:50000/udp` — диапазон динамических портов (Port Hopping) для Hysteria 2.

## ✨ Ключевые возможности

* 🚀 **Протокол VLESS TCP XTLS-Vision (Порт 443 TCP)**: Обеспечивает прямое TLS 1.3 соединение со стандартным профилем клиентского рукопожатия (`fp=random` по умолчанию, настраивается на `chrome`, `ios`, `firefox`).
* ⚡ **Hysteria 2 (Порт 443 UDP)**: Протокол на базе UDP/QUIC для обеспечения стабильной связи и минимального RTT в мобильных сетях с потерями пакетов.
* ↔️ **Протокол VLESS gRPC (Порт 8443 TCP)**: Резервный мультиплексированный канал поверх HTTP/2 и TLS.
* 📱 **Сервер динамических конфигураций (Base64 / JSON)**: Локальный сервис генерирует персональные профили подключения (`https://ваш-домен.com/sub/UUID`). Совместим с приложениями **Happ**, **Incy**, **Hiddify**, **v2rayN**, **Shadowrocket**, **Clash/Mihomo**, **SingBox**.
* 🌀 **Селективная маршрутизация через Cloudflare WARP**:
  * **Smart (Рекомендуемый)**: Направляет через Cloudflare только выбранные внешние ресурсы и детекторы IP.
  * **Full**: Направляет весь исходящий трафик сервера через Cloudflare.
* 🌀 **Маршрутизация облачных AI-сервисов (OpenAI / Claude)**: Направление запросов к AI-платформам через выделенный резидентный прокси-канал.
* ⚡ **Комплексная оптимизация VPS**:
  * **Гибридная память**: ZRAM (50-60% RAM с LZ4) + 2GB Disk Swap.
  * **Сетевой стек**: Тюнинг `sysctl` (`fs.file-max=67M`, BBR, TCP Fast Open, сетевые буферы до 32MB).
  * **PMTU Fix**: Автоматический TCP MSS Clamping против фрагментации пакетов.
  * **Ядро Xanmod**: Автоматическая сборка под процессорную архитектуру (v1-v3).

## 🏷️ Формат профилей и обозначений

При импорте конфигурации в клиентское приложение формируются следующие профили подключения:

| Протокол | Формат имени в клиенте | Порт и транспорт | Назначение |
|---|---|---|---|
| **VLESS TCP** | `🇳🇱🌐 VLESS-TCP` | `443/tcp` (XTLS-Vision, TLS 1.3) | Основной высокоскоростной профиль для повседневного использования |
| **VLESS gRPC** | `🇳🇱↔️ VLESS-gRPC` | `8443/tcp` (gRPC, HTTP/2) | Резервный канал передачи данных |
| **Hysteria 2** | `🇳🇱⚡ Hysteria2` | `443/udp` (QUIC, UDP) | Низкие задержки в мобильных и нестабильных сетях |
| **VLESS Reality** | `🇳🇱🪞 VLESS-Reality` | `443/tcp` (Reality) | Режим маскировки под внешние веб-ресурсы (опционально) |

## 🤝 Совместимость с локальными шлюзами (AntiZapret)

Проект спроектирован для безопасного сосуществования с **AntiZapret** на одном хосте.

Инсталлятор автоматически определяет наличие правил AntiZapret, отключает UFW (во избежание конфликтов цепочек NAT) и добавляет порты Xray/Hysteria напрямую в стандартные таблицы `iptables`.

## ❓ Troubleshooting & Часто задаваемые вопросы (FAQ)

### 1. Ошибка при получении сертификата Certbot ("Порт 80 занят")
* **Причина**: На сервере уже активен другой веб-сервер (Nginx, Apache, Caddy).
* **Решение**: Временно остановите конфликтующую службу (`systemctl stop nginx`) на время получения сертификата.

### 2. Соединение Hysteria 2 не устанавливается на облачном VPS
* **Причина**: В панели управления облачной инфраструктуры (Security Groups / Firewall) не открыты входящие UDP-порты.
* **Решение**: Добавьте разрешающие входящие правила для `443/udp` и диапазона `20000-50000/udp`.

### 3. Как обновить ядро или применить обновления?
* Запустите `xry`, выберите пункт **8** («Обновить скрипт с GitHub»), либо выполните `sudo bash install_xray.sh --update-core`.
